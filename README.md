# OULAD Analysis
Please download needed dataset and put files directly in this folder.
Download [OULAD](https://analyse.kmi.open.ac.uk/open-dataset)

## Files Guide
- preprocess.ipynb --> For data preprocessing. ** Run it first **
- dl.ipynb --> Deep learning and shap value analysis.
- mixed_effect.R --> Mixed effect model in R.
- plot.ipynb --> Hist plot for preprocessed data.
- description.ipynb --> Unused clustering correlation matrix.
